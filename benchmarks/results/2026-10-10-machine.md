# Measurement setup, 2026-10-10

Shared by `2026-10-10-baseline.md` and `2026-10-10-after.md`.

* CPU: Intel(R) Xeon(R) Processor @ 2.10GHz, 4 vCPUs (a shared cloud
  container; other jobs ran on the machine, load average ~1).
* OS: Linux 6.18 (x86_64), glibc; valgrind 3.22.0.
* Rust: rustc 1.97.0 (2d8144b78 2026-07-07), workspace release profile
  (`lto = "fat"`, `codegen-units = 1`, `debug = "line-tables-only"`),
  no `target-cpu` flags (baseline x86-64: SSE2).
* Baseline binary: commit `acc9631` (`develop` plus a test-only fix).
* After binary: the tip of `feature/performance` with all optimisations.

Commands (both binaries copied aside first):

```sh
ROUNDS=7 FRAMES=3000 benchmarks/run.sh gase-baseline gase-after
benchmarks/callgrind.sh gase-baseline     # FRAMES=300
benchmarks/callgrind.sh gase-after
callgrind_annotate --inclusive=no target/callgrind/<rom>.out | head -40
```

Noise: fps on this machine varies by a few percent between runs (complete
7-round runs of the comparison gave speedups between 1.50x and 1.92x per
ROM); the tables use the last run, made on the final binary with nothing
else of ours running. The baseline fps in `2026-10-10-baseline.md` comes
from that same run.
Instruction counts are reproducible to within a few thousand instructions.
